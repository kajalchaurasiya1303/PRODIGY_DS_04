# PRODIGY_DS_04 – Sentiment Analysis and Visualization

## Prodigy InfoTech Data Science Internship

### Task 04

### Objective
Analyze and visualize sentiment patterns in social media data to understand public opinion and attitudes towards specific topics or brands.

## Dataset
The dataset used for this task is **twitter_validation.csv**.

It contains social media posts with information such as Tweet ID, Topic/Brand, Sentiment, and Tweet Text.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Data Cleaning
The following data cleaning steps were performed:

- Loaded the Twitter dataset.
- Assigned appropriate column names.
- Checked for missing values.
- Removed rows containing missing values.
- Removed duplicate tweets.

## Exploratory Data Analysis
The following analysis was performed:

- Analyzed the overall sentiment distribution.
- Compared sentiment across different topics/brands.
- Identified the most frequently mentioned topics/brands.
- Visualized sentiment patterns using bar charts.

## Visualizations

### 1. Overall Sentiment Distribution
A bar chart was created to show the number of tweets belonging to each sentiment category.

### 2. Sentiment by Topic / Brand
A bar chart was created to compare positive, negative, neutral, and irrelevant sentiments across different topics or brands.

### 3. Top 10 Topics / Brands
A bar chart was created to identify the most frequently mentioned topics or brands in the dataset.

## Conclusion
The social media dataset was cleaned and analyzed to identify sentiment patterns and public attitudes towards different topics and brands. The visualizations make it easier to understand the distribution of sentiments and compare public opinion across different topics.
